POSSE課題のフォルダ構成

workspace/
└── POSSE-Kadai/
    ├── PH1/
    │   ├── week01_POSSE-Kadai/
    │   │   └── index.html
    │   ├── ...
    │   └── week04_POSSE-Kadai/
    │       └── index.html
    ├── PH2/  week05_POSSE-Kadai/ 〜 week08_POSSE-Kadai/
    ├── PH3/  week09_POSSE-Kadai/ 〜 week12_POSSE-Kadai/
    └── PH4/  week13_POSSE-Kadai/ 〜 week16_POSSE-Kadai/

※ PH2〜PH4 の各 week フォルダにも、PH1 と同じように index.html を置きます。

注意：ファイル名・フォルダ名は半角英数字と - _（と拡張子の .）で付ける

例：POSSE課題.html → POSSE-Kadai_Setumei.html

日本語を避ける理由

  • Git の表示で "POSSE\350\252\262..." のように文字化けする
  • URL に含めると %E8%AA%B2... と変換され、リンクが扱いにくい
  • Mac と Windows で文字の扱いが違い、別のファイルとして認識されることがある

記号を避ける理由

  • スペース：ターミナルで "my file.html" と囲む必要があり、URL では %20 になる
  • \ / : * ? " < > |：Windows では使えず、clone に失敗する
  • # % &：URL で特別な意味を持ち、リンクが壊れやすい
  • ( ) ! $：ターミナルで特別な意味を持ち、入力ミスの原因になる
  • . で始める：Mac / Linux では隠しファイルになる
